📡 Skema Pengkabelan & Pinout ESP32:

Komponen Sensor / Aktuator Tipe Sinyal Rekomendasi Pin ESP32
DHT22 (Suhu & Kelembapan Udara) Digital Data GPIO 16
Capacitive Soil Moisture (Kelembapan Tanah) Analog ADC GPIO 35 (ADC1_CH7)
Sensor pH Analog (Derajat Keasaman) Analog ADC GPIO 34 (ADC1_CH6)
Sensor pH Digital (DO / Trigger pH) Digital Input GPIO 13
Relay 1 (Pompa Penyiraman Air) Digital Output GPIO 26
Relay 2 (Pompa Pupuk Cair) Digital Output GPIO 27

🌐 Endpoint REST API untuk ESP32:

POST https://aquasmart-iot.onrender.com/api/telemetry

Format Payload JSON yang dikirim ESP32:

{
  "suhu": 28.5,
  "kelembapan": 42.0,
  "ph": 6.75,
  "deviceId": "ESP32-Greenhouse-1"
}

Server akan mengembalikan status relay terkini:

{
  "success": true,
  "controls": {
    "mode": "auto",
    "pompaAir": true,
    "pompaPupuk": false
  }
}

Salin kode ini dan upload ke ESP32 Anda via Arduino IDE. File juga tersedia di folder esp32_firmware/esp32_penyiraman.ino.

/*
  🌱 AquaSmart IoT - ESP32 Fuzzy Tsukamoto Smart Irrigation
